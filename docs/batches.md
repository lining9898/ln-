- BATCH 0：架构与项目初始化
- BATCH 1：Windows 桌面框架 + 中文 UI
- BATCH 2：知识库创建/删除/管理
- BATCH 3：文件导入
- BATCH 4：PDF/DOCX/TXT/MD 解析（含扫描页 OCR）
- BATCH 5：SQLite 数据层及前期数据迁移
- BATCH 6：全文检索
- BATCH 7：本地 Embedding + 语义检索
- BATCH 8：混合检索
- BATCH 9：原文查看/来源定位
- BATCH 10：DeepSeek API 与安全凭据
- BATCH 11：RAG AI 问答
- BATCH 12：引用与证据展示
- BATCH 13：多知识库联合问答
- BATCH 14：备份/恢复
- BATCH 15：Windows 打包
- BATCH 16：完整验收

## BATCH 1 具体计划

1. 添加 WPF 应用入口、主窗口和轻量 MVVM，构建桌面应用。
2. 五个中文导航：AI问答、知识库、文档搜索、文件管理、设置。
3. 首页展示选择知识库、空聊天区、输入框与“资料保存在本机”提示；无知识库/无 Key 时明确空状态，不制造可用功能。
4. 其他页面仅提供中文布局及空状态；不提前实现导入、数据库、AI 请求。
5. 引入统一用户数据路径服务，程序目录和用户数据分开；不保存凭据。
6. Windows 编译、启动、导航、缩放/高 DPI、中文/空格路径及重启冒烟验证；截图交用户确认 UI。
7. 报告实际通过与环境未覆盖项，独立提交，再推进下一批。

## 最小闭环限制

BATCH 2–12 所有实现仅服务于一个库、一个文件的导入→搜索→问答→证据→原文闭环。
BATCH 12 先验收闭环，通过后才进入联合问答、备份与打包。不增加 XLSX/PPTX 或其他额外功能。
BATCH 16 使用用户提供结构规范和另一套普通资料，验证通用性、编号精确检索、页码与回答依据。
真实 PDF、人工 OCR/引用核对和 API Key 在确实需要的批次请求；当前不需要。
