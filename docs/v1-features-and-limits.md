# V1 功能清单与已知限制

## 功能

- Windows 10 x64 WPF 中文界面；多知识库管理，文档归属隔离。
- 导入 PDF、DOCX、TXT、MD；扫描 PDF 本地中文 OCR。
- SQLite 本地持久化、FTS5 中文关键词检索、来源位置及 PDF 物理页码文字预览。
- 本地哈希文本向量与混合检索；DeepSeek 问答和引用核验。
- 可选 Tavily 公网搜索与知识库综合回答；本地与网页引用分别显示。
- PDF 引用和搜索来源可打开原始页面，支持物理页码跳转与缩放。
- Windows Credential Manager 密钥存储；自包含安装包与便携 ZIP。
- 备份与恢复服务；独立目录恢复已验收。

## 已知限制

- 原始 PDF 按页渲染为图像，可核对版式；查看窗口中无法直接选取文字或编辑批注。
- 部分缺少字体映射的 PDF 文字可能显示不全，可点击“系统阅读器”用默认 PDF 程序核对原文件；系统阅读器不保证自动跳页。
- 备份与恢复服务无图形界面入口；人工备份请关闭程序后复制完整数据目录。
- DeepSeek 真实联网问答尚未用用户 Key 验证；“测试连接”会产生真实 API 调用。
- Key 输入框在输入时可见，保存后清空并存入 Windows Credential Manager。
- 当前交付版本为 0.2.0，安装器与主程序版本已统一。
- 公网搜索需要单独的 Tavily Key，可能消耗额度；真实联网综合问答尚未完成验收。
- 安装向导目前使用英文；软件主界面为中文。
- OCR 结果可能有识别错误，应核对原始扫描页。
